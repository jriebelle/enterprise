Shopkite Accounts API Reference

Comprehensive reference documentation for the authentication and password reset REST APIs in Shopkite Accounts.

Base URLs

  • Local: http://127.0.0.1:8000/api
  • Production: https://accounts.shopkite.com.ng/api

Global Headers

  • Accept: application/json
  • Content-Type: application/json

Authentication Overview

Protected endpoints utilize Bearer Token authentication via the HTTP Authorization header: 

Authorization: Bearer <token>

Tokens are 60-character cryptographically secure random strings generated upon successful sign-in (POST /api/auth/login). When logging out via POST /api/auth/logout, the active Bearer token is invalidated immediately.

POST GET /api/auth/check-email alias: /api/check-email

Check whether an email address already exists as an active user. Useful for pre-registration checks, onboarding validation, or routing users to login.

Request Parameters
ParameterTypeRequiredDescription
emailstringYesThe email address to check (case-insensitive)
Request Examples
POST (JSON Body)
{
  "email": "user@example.com"
}
GET (Query Parameter)
GET /api/auth/check-email?email=user@example.com
Success Responses

  "exists": true,
  "message": "Email address exists.",
  "data": {

  "exists": false,
  "message": "Email address does not exist.",

POST /api/auth/logout alias: /api/logout

Invalidates the authenticated user's active Bearer token.

{
  "success": true,
  "message": "Signed out successfully."
}
POST /api/auth/password/forgot alias: /api/password/forgot, /api/password/email

Initiates a password reset by generating a 6-digit numeric OTP code and sending it to the user's registered email address. The code remains valid for 60 minutes.

Request Parameters
ParameterTypeRequiredDescription
emailstringYesUser's registered email address
Success Response 200 OK 
{
  "success": true,
  "message": "A password reset code has been sent to your email address."
}
POST /api/auth/password/verify-code alias: /api/password/verify-code

Validates that the 6-digit reset code provided by the user matches the active token and has not expired.

Request Body Example 
{
  "email": "user@example.com",
  "code": "481920"
}
POST /api/auth/password/reset alias: /api/password/reset

Completes the password reset process by verifying the OTP code, updating the user's password, rotating authentication tokens, and removing the OTP record.

Request Body Example 
{
  "email": "user@example.com",
  "code": "481920",
  "password": "myNewStrongPassword456",
  "password_confirmation": "myNewStrongPassword456"
}

Code Examples

JavaScript / Fetch (Client-Side)
Check If Email Exists (NEW)
async function checkEmail(email) {
  const response = await fetch('https://accounts.shopkite.com.ng/api/auth/check-email', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'application/json'
    },
    body: JSON.stringify({ email })
  });

  const data = await response.json();
  if (response.ok && data.success) {
    return data.exists; // boolean: true or false
  } else {
    throw new Error(data.message || 'Email check failed');
  }
}
Login and Store Bearer Token
async function login(emailOrPhone, password) {
  const response = await fetch('https://accounts.shopkite.com.ng/api/auth/login', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'application/json'
    },
    body: JSON.stringify({
      login: emailOrPhone,
      password: password
    })
  });

  const data = await response.json();

  if (response.ok && data.success) {
    localStorage.setItem('auth_token', data.token);
    console.log('Signed in successfully as:', data.user.firstname);
    return data.user;
  } else {
    throw new Error(data.message || 'Login failed');
  }
}

Security Guidelines

  • Always use HTTPS in production: Ensure all API requests are transmitted over TLS/HTTPS.
  • Never expose tokens client-side in public URLs: Tokens should only be transmitted via the Authorization: Bearer <token> header.
  • OTP Expiry: Password reset codes expire after 60 minutes and are immediately deleted upon successful password reset.
